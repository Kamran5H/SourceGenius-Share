📖 Welcome to Source Genius v7.1.49! Follow the steps below to get fully set up with team collaboration and database sync.
1 Register Your Profile
On first launch, enter your Name and Email in the welcome screen. This identifies you in the team database and CSV exports.
You can update your profile anytime in ⚙️ Settings → Your Profile.
2 Deploy the Companion Script (Admin Only)
Admin setup (one-time):
1. Open your Google Sheet → Extensions → Apps Script
2. Copy the full companion.gs script from ⚙️ Settings → Companion Script
3. Paste it into the Apps Script editor → Save
4. Click Run → setupSheet() — this creates Database, Members, Activity sheets and shows your secrets
5. Go to Deploy → New Deployment → Web App
   Set Execute as: Me and Access: Anyone
6. Copy the Web App URL and your App Secret (shown in the popup)
3 Connect to the Database
Go to ⚙️ Settings → Database Integration and enter:
• Database Web App URL — the Google Apps Script deployment URL
• Database App Secret — the BWF_XXXXXX secret shown during setup

Your results will now automatically sync with the team database. The extension checks for duplicates before processing each brand.
4 Team Members — Approval & Email Verification
New members:
1. Register name & email in the extension → status shows Pending
2. Click 📧 Send Verification Email in the registration screen
3. Check inbox for the 6-digit code → enter it → click ✅ Verify
4. Account is now active — extension unlocked!

Admin alternative: Go to 👥 Team tab → manually approve members from Pending Approvals

Blocked users cannot start jobs — admin can block/unblock from the Team tab.
4b Live-Write Sheet for Each Team Member
Each team member can connect their own personal Google Sheet to receive results in real time. This is separate from the shared Admin database.

Setup (do this on your own computer):
1. Go to sheets.google.com → + New · name it "My Brand Results"
2. Extensions → Apps Script · delete all code · paste the User Sheet Script from ⚙️ Settings below
3. Run setupMySheet() → Allow → copy the BWF_... secret shown
4. Deploy → New Deployment → Web App · Execute as: Me · Access: Anyone · copy URL
5. Extension → ⚙️ Settings → Live Results Sheet → paste URL + Secret → Save All Settings

📋 The User Sheet Script is available in ⚙️ Settings → User Live-Write Sheet Script.
5 Running Your First Job
Option A — Paste ASINs: Go to ⚡ Agent → paste Amazon URLs or ASINs (one per line) → click ▶ Start

Option B — Amazon Scraper: Open Amazon.com, search any keyword → switch to 🕷️ Amazon Scraper tab → click Scrape → then ▶ Start

Option C — Keywords: Use the 🔑 Keywords tab to paste keywords or upload a CSV — the agent will scrape Amazon for each keyword automatically.

Use ⬇ Queue CSV to download the scraped ASIN list at any time.
6 Exporting Results
• 📋 Results tab → ⬇ Export CSV: Downloads all found brands and websites (duplicates excluded)
• 📋 Copy (Sheet): Copies results as tab-separated values for direct paste into Google Sheets
• Results are also live-written to your Google Sheet if connected (configure in 📊 Google Sheets Auto-Write)
• Use Manage Results buttons to remove duplicates or not-found entries
7 Automation Settings (v5.0)
In ⚙️ Settings → Automation:
• Auto-remove duplicates: cleans up duplicate rows automatically after each job
• Auto database sync: re-checks results against the DB after job completes
• Live-write filter: choose whether to write all results, only found brands, or exclude duplicates to your Sheet
• Save not-found to DB: also records brands with no website in the database
• Auto-click CAPTCHA: experimental — tries to auto-click the Google robot check
8 Tips for Best Results
• Use Balanced or Stealth mode for large overnight runs to avoid CAPTCHA
• Set Search Delay to at least 1.2s to reduce blocking
• Use a VPN for very large jobs (1000+ ASINs)
• DB Duplicate Sync is the most powerful deduplication — it checks your entire existing database
• The admin's Admin Secret must be kept private — it grants access to approve/block members
