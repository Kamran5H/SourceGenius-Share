# Source Genius — Shareable Setup Package (v7.1.54)

> **Owner:** Kamran Ashraf. This is the **distributable bundle** of Source Genius for setting up on a new laptop. See `README.txt` for the full step-by-step setup guide.

## The two parts (you need BOTH)

1. **`extension/`** — the Source Genius Chrome extension (the UI + pipeline).
2. **`scraper/`** — the "brand reader": a small program that reads Amazon through **real Chrome** so Amazon doesn't block it. Without this, the extension runs but produces mostly errors.

## Quick start

- Double-click **`START-HERE.bat`**, or follow **`README.txt`** exactly.

Full instructions, including why the scraper is required, are in `README.txt`.
